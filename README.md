# Python 2025 — Archivo de Aprendizaje y Prácticas

Repositorio histórico que recopila los ejercicios, módulos de formación, prácticas guiadas y mini-proyectos desarrollados en **Python** durante mi etapa de aprendizaje en 2025.

> **Nota para reclutadores:** Este repositorio funciona como archivo de estudio y evolución técnica. Para ver proyectos completos con arquitectura limpia, pruebas automatizadas y Docker, revisa mis repositorios principales:
> - [inventory-fastapi](https://github.com/YamitGC/inventory-fastapi) — API REST en Python con FastAPI, PostgreSQL, Docker y Pytest.
> - [helpflow](https://github.com/YamitGC/helpflow) — Plataforma de microservicios con Spring Boot 3, Java 21, arquitectura hexagonal y cobertura JaCoCo.
> - [mining-engine-management](https://github.com/YamitGC/mining-engine-management) — Sistema full-stack con microservicios, TypeScript y Docker Compose.

## Temas practicados

- Sintaxis base, estructuras de datos, control de flujo y funciones.
- Programación Orientada a Objetos (encapsulamiento, herencia, polimorfismo y composición).
- Manejo de errores, depuración y `logging`.
- Lectura/escritura de archivos y conexión básica a bases de datos SQL.
- Interfaces gráficas de escritorio con `tkinter`.
- Organización inicial en arquitectura MVC.

## Requisitos y ejecución

- **Python 3.10+**

Para ejecutar cualquier script individual:

```bash
git clone https://github.com/YamitGC/python-2025.git
cd python-2025
python3 ruta/al/archivo.py
```

Algunos módulos utilizan librerías externas (como `pandas`, `psycopg2` o `qrcode`), las cuales pueden instalarse en un entorno virtual según el script que se desee probar.
